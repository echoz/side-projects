02 / The system

From wrist to terminal.

A focused stack for collecting, keeping, and reading workout observations.

  1. 01

    Transponder

    A Garmin Connect IQ data field built in Monkey C, designed to collect measurements alongside native Garmin recording.

    Garmin simulator verified
  2. 02

    Pitwall

    A Linux-first SwiftNIO service. Authenticated batches are committed to SQLite before acknowledgment; identical retries are safe.

    Durable local path
  3. 03

    Your terminal

    A scriptable CLI and a Chio terminal interface read the same stored snapshots, with periodic refresh and visible read failures.

    CLI + terminal UI
≠

Missing is different from zero.

A missing measurement stays missing. A failed read stays visible. A fresh connection alone doesn’t establish a fresh measurement or a finished workout.
