Behind the glow

A small screen.
A thoughtful system.

One long-lived Swift host coordinates separate plugin processes. Sources supply facts, a provider chooses what matters, and Marquee keeps the pixels up to date.

  1. 1

    Bring the context.

    Source plugins publish typed facts and updates. The implemented scripted source provides synthetic quota and workout observations.

  2. 2

    Choose the moment.

    The default heuristic or an optional model provider selects a complete host-prepared screen or continues an existing selection. The model does not draw pixels or author layouts; the host owns disclosure, turn timing, formatting and reflow.

  3. 3

    Give it some glow.

    A display plugin receives the rendered frame: USB to a WLED TC001, or a local SVG simulator with a read-only true-color terminal viewer. Cached dependencies allow USB output and the simulator to work without a network.

Development status / October 7, 2026
IMPLEMENTED / MACOS

Automatic and manual billboards

Synthetic quota → workout → quota, live progress, privacy filtering, fallback and manual override run through real source, provider and simulator processes. The CLI and Swift client share the host’s control path.

VERIFIED / SOFTWARE

Tests and simulator evidence

Recorded macOS unit and integration tests exercise the host, plugins and simulator with synthetic inputs and test-owned resources. These checks do not establish live-account, remote-model or physical-display behavior; those need separate evidence.

EXERCISED / PHYSICAL DEVICE

TC001 over USB

Text, replace/clear and a text/progress demo have been user-confirmed. The latest specifically dated device check, September 21, sent RUN at 60% and 75%, then COFFEE; the user confirmed seeing COFFEE. That is separate from software-test evidence.

OPTIONAL / QUALITY UNDER EVALUATION

Model-backed selection

Configurable model providers support Chat Completions and Responses. Bounded synthetic trials demonstrate accepted selections and live bindings. Valid replies alone do not establish good judgment, useful rotation, acceptable latency or unattended readiness.

PLANNED / NOT IMPLEMENTED

Beyond the first display

Real quota/workout integrations, TC002, general animation, managed plugin installation and runtime USB/plugin recovery remain unfinished. Simulator recording/playback and complete cross-platform adapters are also future work.
